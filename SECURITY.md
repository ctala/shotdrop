# Security policy

Please **do not** open a public issue for a vulnerability.

Report it privately through [GitHub's private vulnerability reporting](https://github.com/ctala/shotdrop/security/advisories/new). You will get a first answer within a few days. Once a fix is released you will be credited, unless you prefer not to be.

In scope: the extension (`extension/`) and the server (`worker/`), for example a way to upload or delete without the token, to read a screenshot without its key, or to leak the token.

The threat model is in the README, under [Security](README.md#security).
